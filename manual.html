1. ระบบนี้คืออะไร

เว็บ IDE + ทีม AI 5 ห้อง (terminal จริง) ในหน้าเดียว ประกอบด้วย 2 โปรแกรมที่แยกกันรัน:

โปรแกรมไฟล์หน้าที่
Web serverhud-web.mjsเสิร์ฟหน้าเว็บ, editor แก้ไฟล์, เป็นตัวกลาง API — รีสตาร์ทได้โดยแชตไม่หาย
PTY daemonpty-daemon.mjsอุ้ม terminal ทั้ง 5 ห้อง + ฐานข้อมูล SQLite — ห้ามฆ่าตอนใช้งาน แชตหายหมด

ห้องทั้ง 5: 0: SUPERAGENT (สั่งงาน) 1: DEEP RESEARCH (ค้น) 2: SANDBOX CODER (เขียนโค้ด) 3: ARTIFACT CREATOR (docs+test) 4: MEMORY VERIFIER (ตรวจ)

3. สิ่งที่ต้องมีก่อนติดตั้ง

  • Node.js 22 ขึ้นไป — เช็คด้วย node -v (โปรเจกต์นี้ใช้ v24)
  • macOS หรือ Linux (Windows ใช้ผ่าน WSL)
  • พอร์ต 5999 ว่าง
  • อินเทอร์เน็ตรอบแรก (โหลด editor/xterm จาก CDN + npm install)

4. ติดตั้งทีละขั้น (ครั้งแรก)

# 1) เข้าโฟลเดอร์โปรเจกต์
cd "/path/to/project"

# 2) ลง dependency (ครั้งเดียว)
npm install ws node-pty

# 3) macOS: ถ้า node-pty spawn ไม่ผ่าน ให้ permission helper
chmod +x node_modules/node-pty/prebuilds/*/spawn-helper 2>/dev/null; true

# 4) ให้สิทธิ์รันสคริปต์
chmod +x server.sh squad.mjs hud-web.mjs pty-daemon.mjs

# 5) สตาร์ท
./server.sh start
# เปิด http://localhost:5999 แล้วกด LAUNCH ALL 5
ย้ายโฟลเดอร์ไปเครื่องอื่นได้เลย — ทุก path ในโค้ดอ้างอิงตำแหน่งตัวเอง/โฟลเดอร์ปัจจุบัน ไม่มี path ตายตัว ยกเว้นไฟล์ข้อมูลใน ~/.gemini/antigravity-cli/ ที่จะถูกสร้างให้ใหม่อัตโนมัติ

5. เปิดใช้งานประจำวัน

./server.sh start     # เปิดเว็บ (daemon ติดเอง)
./server.sh restart   # อัปเดตโค้ดแล้วรีเฉพาะเว็บ — แชตไม่หาย ไม่ต้องเปิด agy ใหม่
./server.sh stop      # หยุดแค่เว็บ (แชตยังค้างใน daemon)
./server.sh status    # ดูว่า web/daemon/ห้องไหน live อยู่
./server.sh stop-all  # ล้างกระดาน (แชตหาย!) ใช้เฉพาะตอนอยากเริ่มใหม่หมด
ห้าม pkill -f pty-daemon ตอนใช้งาน — นั่นคือปุ่มทำลายแชตทุกห้อง

6. ใช้หน้าเว็บ Workbench

  • ซ้าย: Explorer + Monaco editor (กด Ctrl/⌘+S เซฟ) + Process Runner — ปุ่ม EXPLORER/CODE บน header ซ่อนแผงได้
  • ขวา: 5 tab ห้อง terminal (คลิกสลับ, ปุ่ม GRID ดูพร้อมกัน) — จุด ● เขียว = เชื่อมอยู่, แดง = กำลังต่อกลับเอง
  • ปุ่มประจำห้อง: START AGY / CTRL+C / CLEAR / ↻ RESTART (ฆ่าห้องนั้นเกิดใหม่เมื่อค้าง)
  • แถบบน: สถานะ CLI (model, memory, quota) + แถบ GOAL + แผง HUD/INTER-CHAT/squad

7. สั่งให้ AI คุยกัน

แถบ INTER-CHAT → เลือกห้องปลายทาง → พิมพ์ → กด:

ปุ่มผล
TASKส่งงานแบบติดตามได้ (มีเลข id, ลง inbox, เด้งเข้าจอพร้อมกระดิ่ง)
TELLพิมพ์ดิบเข้าห้องนั้นทันที (เหมือนนั่งพิมพ์เอง)
INBOX (n)เปิดลิ้นชักงานค้างของห้องที่เปิดอยู่ พิมพ์ผลแล้ว ACK+DONE (ผลส่งกลับคนสั่งเอง)
GOAL → SETประกาศเป้าหมายทั้งทีม + เซฟ GOAL.md
SEND (บน header)ตะโกนพร้อมกัน 5 ห้อง

บทสนทนาแรกสุด (3 กด): เลือก 2: SANDBOX CODER → พิมพ์ ทักทายห้อง 0 หน่อย → TASK → ไป tab 2 ดูกรอบงาน → INBOX → พิมพ์ตอบ → ACK+DONE → กลับ tab 0 ดูคำตอบ

8. คำสั่ง squad.mjs ทั้งหมด

รันใน terminal ห้องไหนก็ได้ (AI ใช้เองได้):

node squad.mjs who                  ดูทีม: ใคร live/ดูจออยู่/เงียบไปนานแค่ไหน
node squad.mjs inbox [ห้อง]          ดูงานค้าง (ค่าเริ่มต้น = ห้องตัวเอง)
node squad.mjs ack <id> <ผล>      ปิดงาน + ส่งผลกลับคนสั่งอัตโนมัติ
node squad.mjs task <ห้อง> <งาน>   สั่งงานแบบมีโครง
node squad.mjs send <ห้อง> <msg>   ทักตรง realtime (มีกระดิ่ง)
node squad.mjs listen [ห้อง]        เปิดฟัง realtime ทิ้งไว้ (เห็นทุกข้อความทันที)
node squad.mjs tell <ห้อง> <msg>   พิมพ์ดิบเข้าห้องนั้น
node squad.mjs broadcast <msg>     พิมพ์ดิบเข้าทั้ง 5 ห้อง
node squad.mjs goal [ข้อความ]       ดู/ตั้งเป้าหมายทีม
node squad.mjs claim <ไฟล์> [--shared] [โน้ต]   จองไฟล์ก่อนแก้
node squad.mjs release <ไฟล์>        ปล่อยไฟล์หลังเสร็จ
node squad.mjs claims               ดูว่าใครจองไฟล์ไหน + ไฟล์ไหนเปลี่ยนแล้ว
node squad.mjs knock <ไฟล์> [msg]    เคาะขอร่วมแก้ไฟล์ที่เพื่อนจอง
node squad.mjs skills               ดูสกิลที่มี
node squad.mjs restart [ห้อง]       ฆ่าห้องนั้นเกิดใหม่ (ห้องค้าง/vim)
node squad.mjs lesson               บอก path ไฟล์บทเรียน

9. ร่วมกันเขียนโค้ดไม่เหยียบไฟล์กัน

# ก่อนแตะไฟล์ไหน จองก่อน (คนอื่นมาจะโดนปฏิเสธพร้อมชื่อคนจอง)
node squad.mjs claim src/app.ts "เพิ่มปุ่ม save"

# อยากช่วยไฟล์ที่เพื่อนจอง: เคาะก่อน อย่าพุ่งเข้าไปแก้
node squad.mjs knock src/app.ts "ขอช่วยส่วน validation"
# เจ้าของเปิดโหมดร่วม: node squad.mjs claim src/app.ts --shared "..."

# แก้เสร็จ: ส่งตรวจ + ปล่อย
node squad.mjs task ai-qa "ตรวจไฟล์ src/app.ts ที่แก้ไป"
node squad.mjs release src/app.ts

ไฟล์ที่ถูกแก้ขณะมีคนจอง ระบบสะกิดเจ้าของเอง ([WATCH]) — ดูภาพรวมที่ /monitor แผง EDITING NOW

10. สอน AI ประจำห้อง (ครั้งแรกครั้งเดียว)

เปิดทีละ tab พิมพ์ agy (หรือ AI CLI ที่มี) แล้ววาง:

อ่าน SQUAD.md กับ SQUAD-TALK.md แล้วจำบทตาม $AGENT_ID จากนั้นรัน node squad.mjs who แล้วรายงานว่าตัวเองคือห้องอะไร

ถ้าห้องไหนพูดเรื่อง subagent ของตัวเอง (ไม่รู้จักระบบเรา) เปิด SQUAD-BRIEF.md ก็อปบล็อกไปวางในห้องนั้นได้เลย

11. หน้าจอมอนิเตอร์

http://localhost:5999/monitor (ปุ่ม MONITOR บน header) — การ์ดสถิติ SQLite, ตารางทีมสด, ฟีดข้อความย้อนหลัง (กรองตามห้อง/ชนิดได้), กล่อง GOAL, แผงไฟล์ที่จองอยู่ รีเฟรชทุก 2 วิ

12. แก้ปัญหาเบื้องต้น

อาการแก้
กด LAUNCH แล้ว 500 / start-all error./server.sh restart (socket ค้างจะถูกล้าง+ปลุก daemon ใหม่เอง) ดู log ที่ ~/.gemini/antigravity-cli/pty-daemon.log
ห้องจอดำ / หลุด syncรอ 1.5 วิให้ต่อกลับเอง (จุดแดง→เขียว) ไม่หายกด ↻ RESTART ห้องนั้น
เผลอเปิด vim / ห้องค้างในแอปเต็มจอ↻ RESTART หรือ node squad.mjs restart <ห้อง> (vim ถูกแบนที่ระบบอยู่แล้ว เปิดไม่ได้)
รีเว็บแล้วแชตหายใช้ ./server.sh restart เท่านั้น อย่า pkill daemon เอง
daemon รันซ้ำหลายตัว./server.sh stop-all แล้ว start ใหม่ (มีตัวกันซ้ำในตัว)
node-pty spawn ไม่ผ่าน (Mac)chmod +x node_modules/node-pty/prebuilds/*/spawn-helper
พอร์ตชนHUD_PORT=5998 ./server.sh start (แล้ว squad.mjs ต้องตั้ง HUD_PORT เดียวกัน)

13. ข้อควรระวังความปลอดภัย

  • Server ฟังแค่ localhost (127.0.0.1) — เปิดจากเครื่องอื่นไม่ได้ตามค่าเริ่มต้น อย่าแก้ส่วนนี้ถ้าไม่เข้าใจผล
  • ไม่มีระบบล็อกอิน — ใครเปิดหน้าเว็บได้ = พิมพ์คำสั่งใน terminal ทุกห้องได้ = รันคำสั่งบนเครื่องได้ แชร์โปรเจกต์ได้ แต่ห้ามเปิดพอร์ตออกเน็ตเวิร์ก
  • PTY คือ shell จริงของ user ที่รัน — AI ที่รันคำสั่งได้ = สิทธิ์เท่า user นั้น อย่ารันด้วย root
  • vim ถูกปิดทั้งระบบ (shim + EDITOR=true) ถ้าต้องการใช้คืน ลบโฟลเดอร์ ~/.gemini/antigravity-cli/novin/ แล้วรี daemon

14. คำถามที่เจอบ่อย

Q: ห้องไม่รู้จักรระบบ พูดเรื่อง subagent ของตัวเอง?
A: เอาบล็อกจาก SQUAD-BRIEF.md ไปวางในห้องนั้น

Q: ส่งข้อความแล้วอีกห้องไม่เห็น?
A: อีกห้องต้องเปิด node squad.mjs listen ค้างไว้ หรือดู INBOX — ข้อความไม่หายเพราะอยู่ใน SQLite อยู่แล้ว เช็คที่ /monitor

Q: 2 ห้องพิมพ์หาลีดเดอร์พร้อมกันพังไหม?
A: ไม่พัง คิวตามลำดับ id ไม่ปนกัน ลีดเดอร์ไล่ ack ทีละงาน

Q: AGENT ช่วยกันแก้ไฟล์เดียวได้ไหม?
A: ได้ — เจ้าของเปิด claim --shared แล้วอีกคน claim ตาม ไฟล์เปลี่ยนจะมี [WATCH] เตือนทั้งคู่
