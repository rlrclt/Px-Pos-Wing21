Speed & Lightweight Engine

5 กฎเหล็กเพิ่มความเร็วและลดขนาดฐานข้อมูล (Ultra-Lightweight Rules)

1. ตัดเซลล์และคอลัมน์ว่าง (Sheet Trimming)

สคริปต์ GAS จะสั่งลบคอลัมน์ว่างส่วนเกิน (เช่น คอลัมน์ L ถึง Z) และลบแถวว่างด้านล่างทิ้งทั้งหมด ลดภาระหน่วยความจำ Google ได้ทันที 80%

2. Write-Only Tables (บันทึกเข้าอย่างเดียว)

ตาราง Orders, Order_Items, Splits จะบันทึกแบบ Append แถวใหม่อย่างเดียว ไม่มีการดึงประวัติเก่าขึ้นมาวนลูปอ่านหน้าร้าน

3. กรองเฉพาะ ACTIVE (Filtered Sync)

หน้าร้านดึงเฉพาะทหารที่ status = ACTIVE และสินค้าที่ is_active = TRUE ไม่ดาวน์โหลดข้อมูลที่ไม่ได้ใช้งาน

4. ETag & IndexedDB Cache (0 KB Transfer)

แคชข้อมูลสินค้าลงในเบราว์เซอร์ หากไม่มีการแก้ราคาขาย ระบบจะไม่ดาวน์โหลดข้อมูลใหม่ซ้ำเลย (Transfer = 0 Bytes)
