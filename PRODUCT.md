# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS, Tailwind CSS via CDN

## Users

Developers and users of the Antigravity Agent, looking to understand how the agent thinks and which skills to invoke for different tasks.

## Product Purpose

A clear, categorized dashboard that explains the Antigravity Agent's thinking methods, individual skills, and combo workflows so users can effectively steer the AI in their projects.

## Positioning

An interactive cheat sheet and capability map directly generated and maintained by the AI itself, using modern utility classes.

## Operating Context

Viewed in a web browser, often alongside a terminal or IDE where the agent is being used.

## Capabilities and Constraints

- Thai language content
- Single HTML file output
- Must remain a static dashboard without complex backend logic

## Evidence on Hand

The incumbent file `antigravity_skills.html` contains the correct text, categories, and structure.

## Product Principles

1. Clarity over complexity
2. Actionable takeaways (Combos, Use cases)
3. Fast, standalone, and visually distinct categories
